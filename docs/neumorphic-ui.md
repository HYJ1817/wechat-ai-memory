# 新拟物界面（Neumorphism）

现代面板（`ui/dashboard_window.py`）的视觉基线：**元素和背景同色，只有两个方向的阴影在说明它凸起还是凹陷**。光源固定在左上，全站一致。

本文替代 `UI_MODERN.md` / `UI_DESIGN_PROPOSAL.md` 里关于玻璃材质的描述——那些是上一版的方向，现已不再适用。

## 为什么现在只有浅色

深色背景上没有"受光面"和"背光面"之间的余地，阴影只能变成脏灰。所以这一版**强制浅色**：`native_theme.system_is_dark()` 恒为 `False`，不再跟随系统深色模式。这不是遗漏，是新拟物的前提。

## Qt 里怎么实现一对阴影

一个 `QWidget` 只能挂**一个** `QGraphicsEffect`，所以"一对"阴影必须拆开生成：

- **外侧暗影**：`QGraphicsDropShadowEffect`（`apply_raised`）。这是 Qt 里唯一能让子控件把阴影画到自己矩形之外的机制，卡片之所以能"浮起来"全靠它。
- **左上高光**：在形状内部按四条边分别铺渐变（`paint_surface`）。不占额外控件，也不会被自身矩形裁剪。

凹陷不需要任何 effect：两侧都是形状内部的边带渐变（`paint_recessed`）。

### 两个容易踩的坑

1. **不要用对角线百分比做渐变**。在 290px 宽的输入框上，26% 的斜向渐变会刷白三分之二，看起来像换了底色。边带必须是**固定像素**厚度（`_band()`）。
2. **内阴影要按四条边铺，而不是一个对角渐变**。对角渐变只作用于起点那个角，左右两侧的中段完全没有阴影——输入框会看起来是平的。

## 和设计稿的偏差

设计稿给的凸起是 `8px 8px 16px` + `-8px -8px 16px`。桌面端按一半取值：

| | 设计稿 | 应用内 |
|---|---|---|
| 卡片位移/模糊 | 8 / 16 | 5 / 16 |
| 控件位移/模糊 | 8 / 16 | 3 / 8 |

原因很实际：三栏布局的列间距是 16px，8px 位移加 16px 模糊会让相邻卡片的阴影互相画进对方身上。比例保持不变，观感一致。

## 版式

现代面板只有两根轴：左边一根设置栏，右边整块预览。设置栏按经典窗口的编号分组（01 数据源 / 02 记忆范围 / 03 归档设置），导出按钮和预估固定在栏底，滚动只发生在中间那段。

这不是审美偏好，是新拟物的约束：所有元素同色，分组只能靠**间距和编号**表达。三栏把设置拆到两端时，中间一栏被压到 400 多像素，两侧的阴影还会互相叠进去；一栏到底之后，卡片里每条设置都有同一条左基线，眼睛不用来回跳。

栏宽 372（内容 332）。这个宽度是量出来的：日期框两个并排要 268，四个操作按钮一行要 322，超过这个数滚动区就会横向溢出、右边缘被裁。新增控件时请检查它在 332 内的最小宽度。

## 控件映射

| 场景 | 用法 |
|---|---|
| 卡片 / 面板 | `GlassCard`（保留旧名）→ 凸起，无描边 |
| 卡片内部的块（预估、统计） | `SoftPanel` → 凹陷 |
| 输入框 / 下拉 / 日期 | `nm.SoftLineEdit` / `nm.SoftComboBox` / `nm.SoftDateEdit` → 先画凹陷，再让 Qt 画文字 |
| 按钮 | `PillButton`：常态凸起、按下转凹陷、`primary` 填紫罗兰 |
| 开关 | `ToggleSwitch`：轨道恒凹陷，旋钮凸起；开启时旋钮紫罗兰 |
| 会话行 | 常态不画；hover 凸起；选中凹陷 + 左侧紫罗兰条 |
| 消息气泡 | `SoftBubble`：收发同材质，靠左右位置和发送者颜色区分 |

## 新增控件时

1. 形状先 `nm.paint_surface` 或 `nm.paint_recessed`；
2. 需要外阴影的一律 `nm.apply_raised(widget)`，hover 时 `nm.damp_raised`，离开 `nm.restore_raised`；
3. **不要**在 QSS 里写 `border: 1px solid`，也不要写填充色——需要层级就用凹陷；
4. 文字颜色走 `native_theme.ink*` / `themed_qss`，不要硬编码 `rgba(255,255,255,·)`。

`themed_qss()` 会把低透明度的白色背景改写成 `transparent`，把白色文字反相成深灰；这层兜底让历史样式表不至于在浅色底上"白字白底"，但新代码不该依赖它。
