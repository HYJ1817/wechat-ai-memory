## 🎨 现代化 UI（可选）

> **新功能**: v0.3.7+ 提供现代化的智能家居风格界面

### 视觉特性

- 🌅 **暖色渐变背景** - 米色到浅橙色的柔和过渡
- 💎 **毛玻璃效果** - 半透明卡片设计
- 🔵 **大圆角** - 更柔和的 12-16px 圆角
- 🎯 **渐变按钮** - 橙色系现代化操作按钮

### 快速体验

#### Windows 批处理（推荐）

双击运行主题选择器：

```cmd
start_ui_selector.cmd
```

或直接启动现代版：

```cmd
start_modern.cmd
```

#### 命令行

使用 `--modern` 或 `-m` 参数：

```powershell
.\.venv-gui\Scripts\python.exe app_modern.py --modern
```

### 对比

| 特性 | 经典版 | 现代版 |
|------|--------|--------|
| 背景 | 浅灰色 | 暖色渐变 |
| 卡片 | 白色不透明 | 半透明毛玻璃 |
| 圆角 | 6px | 12-16px |
| 按钮 | 绿色 | 橙色渐变 |
| 风格 | 传统工具 | 智能家居 |
